# @unified-context-broker/contracts

Canonical Zod schemas, TypeScript types, constants, and agent prompt rule templates for the Unified Context Broker ecosystem.

## Overview

The `contracts` package defines the universal type contracts and validation schemas used across all packages and adapters in the Unified Context Broker. It ensures end-to-end type safety and schema validation across the MCP server, CLI, and client integrations.

## Exports

- **Schemas & Types:**
  - `ContextCandidate`: Canonical ranked context slice with scoring and provenance metadata.
  - `RetrievalPlan`: Structured execution plan generated by the query classifier.
  - `SymbolContext`: Structural symbol intelligence (definitions, callers, callee trees, docstrings).
  - `ImpactContext`: Blast radius upstream and downstream dependency graph.
  - `RepositoryMap`: High-level codebase architecture, module responsibilities, and entry points.
  - `DecisionRecord`: Durable Architectural Decision Record (ADR) schema with rationale and alternatives.
  - `HealthReport`: Per-adapter status, latency, version, and item counts.
  - `ToolCall`: Canonical schemas for all 13 MCP tools.
- **Rule Templates:**
  - `DEFAULT_CONTEXT_BROKER_RULE`: Authoritative agent rule template enforcing MCP tool usage over raw file scans.
  - `CONTEXT_BROKER_RULE_CONTENT`: Direct export of the rule content.

## Dependencies

- `zod`: Runtime schema declaration and validation.
